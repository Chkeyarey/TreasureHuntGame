# TreasureHuntGame
## Repository created for Module 7, CS-370
# Summary
In this project, a Deep Q-Learning (DQN) agent was implemented in Python using Keras and TensorFlow to solve a maze pathfinding problem within TreasureHuntGame.ipynb. The provided codebase handled environment transitions, experience replay memory, and neural network layer definitions, while I authored the core qtrain training loop, target network synchronization (target_model), an ϵ-greedy exploration policy, and validation checks using rolling win rates.

Computer scientists model complex real-world challenges by designing algorithms and reinforcement learning agents that automate decision-making without requiring hand-coded rules. Approaching these problems involves converting raw environmental states into structured mathematical vectors, selecting scalable neural network function approximators, and systematically optimizing hyperparameters through empirical validation. Ethically, engineers are responsible for conducting thorough testing across edge cases to ensure algorithmic safety, maintaining strict data privacy, and delivering transparent documentation regarding system behavior and limitations.
